# Experiments

This directory contains auxiliary scripts for threshold sweeps, consistency tests, and bucket optimization.

## Scripts

- `consistency.py` - Analyze scoring consistency from saved data
- `generate_consistency_data.py` - Generate scoring consistency data by running models multiple times
- `filter_consistency.py` - Analyze filter consistency from saved data
- `generate_filter_consistency_data.py` - Generate filter consistency data by running filter models multiple times
- `threshold_sweep.py` - Threshold sweep experiments

Run each script directly when you need it (they are not imported by default).
